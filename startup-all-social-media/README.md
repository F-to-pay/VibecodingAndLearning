# startup-all-social-media

Маленькая C-программа: запускает одной командой сразу пачку вкладок
браузера со ссылками (сейчас — соцсети, но список в `main.c` можно менять
как угодно).

## Как собрать и запустить

### Linux / macOS

```sh
make
./open_tabs
```

На Linux нужен `xdg-open` (есть почти в любом дистрибутиве с GUI),
на macOS используется встроенный `open`.

### Windows

Через MinGW (например, из [MSYS2](https://www.msys2.org/) или w64devkit):

```bat
mingw32-make
open_tabs.exe
```

или руками, без make:

```bat
gcc -Wall -Wextra -std=c11 -o open_tabs.exe main.c -lshell32 -lole32
```

Через Visual Studio (из "Developer Command Prompt"):

```bat
cl /utf-8 /W4 main.c
main.exe
```

`/utf-8` обязателен, иначе MSVC прочитает русские комментарии и строки
как Windows-1251 и выведет кракозябры. Ссылки открываются через
`ShellExecuteA()` — в браузере, который назначен по умолчанию.

## Что дальше можно докрутить

- читать список ссылок из файла/аргументов, а не хардкодить в коде;
- собирать pid дочерних процессов и ждать их в конце через `waitpid`;
- добавить флаг "открыть только вот эти N ссылок" вместо всех сразу.
